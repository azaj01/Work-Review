# Work_Review v1.1.3-rc.2（繁體中文）

1.1.3 的第二個候選版本，不進入穩定自動更新通道；測試資料目錄遷移前請先備份資料。

### 修復
- **macOS 前台視窗採集重寫**（#181）：改為程序內 NSWorkspace/AXUIElement 直接讀取，不再每次輪詢拉起 `osascript` 子程序，消除 Dock 圖示的週期性閃爍。
- **網站分類立即生效**（#178）：分類修改立即反映到總覽與歷史，網域來自視窗標題或 OCR 的站點會被回補並重新分類；無歷史記錄匹配時給出真實提示，不再誤報成功。
- **助手資料意圖路由**（#179）：「本週時間分佈」這類裸資料問題正確進入工作復盤模式；通用對話明確附帶本地資料說明，模型不再虛構權限拒絕。
- **macOS 26 SDK 連結修復**（#184）：AX 屬性常數在現代 SDK 中是巨集而非匯出符號，改用 `CFString::from_static_string` 等價構造，修復 arm64 連結錯誤。
- **codesign 腳本相容 OpenSSL 3**（#185）：優先系統 LibreSSL 輸出傳統 PKCS#12，缺失時回退 `-legacy`，修復 `security import` 報 MAC verification failed。

### 變更
- **預設 AI 模型重新整理**：OpenAI `gpt-6-luna`、Gemini `gemini-3.8-flash`、Claude `claude-sonnet-5-5`、智譜 `glm-5.3-flash`、Kimi `kimi-k2.6`、豆包 `doubao-seed-evolving`、MiniMax `MiniMax-M3`、Groq `openai/gpt-oss-120b`、xAI `grok-4.7`；供應商端點與預設模型統一由 `AiProvider` 提供，不再維護重複清單。

### macOS 安裝說明
首次開啟可能提示「已損壞，無法開啟」，請執行：

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```

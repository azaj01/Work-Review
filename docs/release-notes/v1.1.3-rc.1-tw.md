# Work_Review v1.1.3-rc.1（繁體中文）

1.1.3 的第一個候選版本，僅用於測試，不是穩定版。安裝前請備份資料，尤其是測試資料目錄遷移前。RC 版本不會標記為 Latest，也不透過穩定自動更新通道提供。

### 修復
- 還原受玻璃風格視窗外殼影響的浮層視埠定位，包括時間軸抽屜、分類控制項和日報對話框。
- 緊湊總覽 KPI 副標題保持應有字號（#172）。
- Windows OCR 超長輸入在現有程序內按原生引擎上限截斷，並把文字框映射回原圖。
- 新活動的首次 OCR 不再被重複截圖冷卻期擋住；既有 OCR 併發限制仍然生效。
- 隱私關鍵字自動儲存進行中時，未儲存的設定變更不再遺失。
- 遷移清理或複製前校驗規範化資料目錄路徑，拒絕經別名或符號連結達成的父子目錄目標。
- 自訂分類無需先套用到某個應用或改寫活動歷史，即可重新命名或刪除。
- 語意索引前先儲存 AI 設定，並改進嵌入設定的錯誤提示。
- 移除 Windows 視窗標題規範化中多餘的所有權字串分配，在不放寬 lint 檢查的前提下解決 Windows 專屬的 `clippy::unnecessary_to_owned` 建置失敗。

### 變更
- 簡化截圖時間軸詳情與行內分類選擇：套用分類改為二次點擊確認；刪除與隱私規則修改保留確認對話框。
- 規範化 Windows 應用標題，降低原生 OCR 程序開銷。
- 關閉已評估的五條 RustSec unsoundness 追蹤 issue（#167-#171）；這不代表上游公告已修復，安全與 unsoundness 公告繼續追蹤。
- 接受嚴格的 `vMAJOR.MINOR.PATCH-rc.N` 發布 tag，作為 GitHub 預發布，不替換穩定的 Latest 版本。

### 待驗證
- Windows 原生 OCR 在普通螢幕、4K 與多顯示器下的截圖，包括隱藏 PowerShell 執行。
- 快速切換應用、重啟後隱私儲存持久性、分類管理互動。
- 用可棄資料做遷移，包括危險目標拒絕與中斷恢復。
- 原生安裝包建置、啟動檢查與從 1.1.2 的升級測試。

### macOS 安裝說明
首次開啟可能提示「已損壞，無法開啟」，請執行：

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```

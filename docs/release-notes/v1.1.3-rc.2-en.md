# Work_Review v1.1.3-rc.2 (English)

Second release candidate for 1.1.3. Not offered through the stable automatic-update endpoint. Back up your data before testing data-directory migration.

### Fixed
- **macOS active window collection rewrite** (#181): the hot path now reads the frontmost app in process (NSWorkspace/AXUIElement) instead of spawning `osascript` on every poll, removing the periodic Dock icon flash.
- **Website categories take effect immediately** (#178): category changes now show up in the overview and history right away; sites whose domain came from the window title or OCR are backfilled and reclassified; a truthful notice replaces the false success toast when no history records match.
- **Assistant data-intent routing** (#179): bare data queries such as "this week's time breakdown" now enter work review mode instead of going unanswered; general chat gets an explicit local-data note so models stop inventing permission refusals.
- **macOS 26 SDK link fix** (#184): AX attribute constants are macros rather than exported symbols in modern SDKs; replaced extern statics with equivalent `CFString::from_static_string` construction, fixing arm64 link errors.
- **`setup-codesign.sh` OpenSSL 3 compatibility** (#185): prefers the system LibreSSL legacy PKCS#12 output and falls back to `-legacy`, fixing `security import` "MAC verification failed" errors.

### Changed
- **Refreshed default AI models**: OpenAI `gpt-6-luna`, Gemini `gemini-3.8-flash`, Claude `claude-sonnet-5-5`, Zhipu `glm-5.3-flash`, Kimi `kimi-k2.6`, Doubao `doubao-seed-evolving`, MiniMax `MiniMax-M3`, Groq `openai/gpt-oss-120b`, xAI `grok-4.7`. Provider endpoints and default models are now served from `AiProvider` instead of a duplicated list that had drifted out of sync.

### macOS install note
If macOS reports the app as damaged on first launch, run:

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```
